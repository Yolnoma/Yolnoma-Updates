## ✨ What is Yolnoma?

**Yolnoma** is a modern Windows desktop application designed as a centralized workspace for everyday utilities, developer workflows, gaming tools, and productivity features.

Instead of installing and switching between dozens of small utilities, Yolnoma brings them together in a single interface.

> **One app. Many tools. One workspace.**

The application is built with a modular architecture, allowing new tools and features to be added without turning the interface into a cluttered collection of separate applications.

## 🔄 Automatic Updates

Yolnoma includes an automatic update system designed to keep installations up to date without requiring users to manually download every new release.

The updater uses signed release artifacts and version manifests to safely distribute new versions.

Each release can provide:

* Latest application version
* Release notes
* Signed Windows installer
* Cryptographic signature
* Automatic version detection

This allows Yolnoma to evolve continuously while keeping the update process simple for users.
